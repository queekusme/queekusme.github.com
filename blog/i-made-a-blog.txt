Well, hello there... So I got bored and decided to add a blog to my website and thought I'd do a quick run down of how it works and why I designed it the way I did.

The first thing to take into consideration is that I host on Github Pages. This means that I can only host a static site, so no server-funsies... This however wasnt an issue as I know Javascript fairly well meaning that with a few good applications of document.getElementById(...) I was in business.

If you look at the source code for the index.html you will get a gist of how things work however the basics are: load a page by ID via a query parameter, or 404, parse then display the contents...

Loading is done via a simple fetch to get the content, the fun starts when you want to do more than just set the innerHTMLof the content element.

So far I do 4 different bits of processing to get the final content and a scrape for a metadata tag in order to pull info such as the published date and author.

Tags follow a simple structure >tag_name~data1~data2...< so for example if you wanted to input an image, you would use the tag_name of 'image' and the 'data' would be what goes into the 'src' tag.

Href tags work the same way however takes advantage of the fact that a tag can have multiple data sections, with the first being the human readable text and the second being the link to the content. For Example: >href~This Is A Link To My Mastodon Page~https://mastodon.scot/@queekusme<

New Line tags '\n' are replaced with &lt;br/&gt;

The final tag is the 'meta' tag which is replaced with nothing in the final content but is extracted and json parsed to provide information such as the 'published' date and author'
